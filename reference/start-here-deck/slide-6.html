The same request, twice

One everyday job, before and after. That difference is the product.

The request
A client asks where their project stands, and wants it in writing today.
Without the workspacefive stops, one after another
01open the mail thread, scroll back three weeksa few minutes
02check the calendar for what was actually agreed in the last calla few more
03find the file you sent, hope it is the latest versiona few more
04open the project tool for what is still opena few more
05write the mail from memory and hedge the parts you are unsure aboutthe longest part
With itone run
you say: write the status update for this client
it reads the thread, the calendar, the files, the open tasks
the draft is there, with the real dates and the real numbers
you check it and press send
Half of it comes from memory, and you know it.
Nothing came from memory. You only checked.
The work did not get faster. The looking things up disappeared.
