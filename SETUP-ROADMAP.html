✓ Done. Type hello in Claude Code and get going.

Set up once, about 20 to 30 minutes, after that all you start each day is Claude Code. Do the steps in order. The most important one is step 3: starting Claude in the right folder. It looks harmless, and it is where most people fail.

Part 1 · Install

After this, all the programs are on your machine and your folder is there.

Install the programs

Four small programs, once per machine. On the Mac you do it with one command (brew install node git gh), on Windows through the installers from the respective websites.

Download your folder

You fetch the finished workspace as a folder of its own. Put it in a quiet place like ~/code, not on the desktop or in Documents if those are synced with iCloud or OneDrive.

Start Claude in the right folder

The most important step. The assistant always reads the folder you start it in. If you start it somewhere else, it doesn't know your system, entirely without an error message, and answers like a normal chat.

Part 2 · Connect

After this, the assistant knows you and is hooked up to your systems and tools.

Just write "hello"

Type hello and press Enter, nothing more. The assistant notices that the folder doesn't belong to anyone yet, and asks you everything important itself: name, role, your working language, your projects. Reckon with 10 to 20 minutes.

Connect mail and calendar

So that your morning briefing knows your appointments and mail drafts land in the right mailbox. You do this once in Claude Cowork under Settings. Without it everything else still runs, only the mail and calendar part is missing.

Add two helpers

Two small additional tools are part of it: one fetches web content (firecrawl), one drives a real browser for forms, logins and screenshots (playwright).

Store an access key

firecrawl needs a key of its own. It never belongs in your folder, but in a separate file alongside it. The access belongs to you, so billing and usage run on your side.

Part 3 · Get going

One last test, then everything runs and your working day can start.

Test everything once

Finally you check that everything really runs. If that works, the setup is done. From tomorrow on you only type /morning in the morning and your day is prepared.

Optional, doesn't count towards the total

Two extras that make everyday use more pleasant. You can add them later at any time.

OPTIONAL

Let the briefing run by itself

Whoever has to type /morning in the morning will eventually forget it. A routine does it for you on a schedule, in the cloud. The result then sits in your online folder and comes to you with a git pull.

OPTIONAL

Talk instead of typing

This system lives on you telling the assistant things. Typing is the brake. Wispr Flow turns your speech into clean text, in any input field, in German too. The first month is free.
