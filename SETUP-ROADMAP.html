Setup-Roadmap

Hak jeden Schritt ab, während du ihn erledigst. Dein Fortschritt bleibt gespeichert, auch nach dem Neuladen.

0 von 0 erledigt
✓ Fertig. Tipp hallo in Claude Code und leg los.

Einmalig pro Person, etwa 20 bis 30 Minuten. Die Reihenfolge zählt: Schritt 2 ist der Punkt, an dem die meisten Setups scheitern. Nimm ihn ernst, auch wenn er trivial aussieht.

0✓

Voraussetzungen

Vier Bausteine, einmalig pro Rechner. Auf dem Mac erledigt das brew install node git gh in einem Rutsch, auf Windows lädst du Node und Git über die Installer.

1✓

Repo klonen

Hol dir den Workspace in einen eigenen Ordner wie ~/code. Nicht nach Desktop oder Dokumente, wenn die mit iCloud oder OneDrive synchronisiert werden, sonst entstehen Konfliktkopien.

2✓

Claude Code IN diesem Ordner öffnen

Der wichtigste Schritt. Claude Code liest immer den Ordner, in dem es gestartet wurde. Startest du es woanders, kennt es dieses System nicht, ganz ohne Fehlermeldung.

3✓

Erster Start

Tipp hallo und drück Enter, mehr nicht. Claude erkennt selbst, dass der Ordner noch niemandem gehört, und startet die Einrichtung. Rechne mit 10 bis 20 Minuten.

4✓

Connectors verbinden

Damit das Morgen-Briefing deinen Kalender kennt und Mail-Entwürfe im richtigen Postfach landen. Das läuft einmal in Claude Cowork unter Einstellungen. Ohne Connector funktioniert der Rest weiter, es fehlt nur der Mail- und Kalender-Teil.

5✓

Empfohlene Werkzeuge

Zwei Kommandozeilen-Helfer gehören zur Standard-Ausstattung. firecrawl holt Web-Inhalte, playwright steuert einen echten Browser für Formulare, Logins und Screenshots.

6✓

API-Schlüssel

firecrawl braucht einen eigenen Zugang. Schlüssel gehören nie ins Repo, sondern in eine einzige Datei außerhalb davon. Der Account gehört euch, so laufen Abrechnung und Nutzung bei euch.

7✓

Smoke-Test

Einmal alles prüfen, damit nichts halb konfiguriert bleibt. Läuft das durch, ist das Setup fertig. Ab morgen ist /morning dein täglicher Einstieg.

Optional

Zwei Erweiterungen, die den Alltag angenehmer machen. Sie zählen nicht in den Fortschritt und du kannst sie jederzeit später nachholen.

OPTIONAL

Das Briefing automatisch laufen lassen

Wer morgens /morning tippen muss, vergisst es irgendwann. Eine Routine führt die Aufgabe zeitgesteuert aus, in Anthropics Cloud mit einem frischen Klon eures Repos. Das Ergebnis erscheint bei dir nach einem git pull.

OPTIONAL

Diktieren statt Tippen

Dieses System läuft über Text im Chat, genau da sitzt die Bremse. Wispr Flow wandelt Sprache in sauberen Text um, in jedem Eingabefeld, auch auf Deutsch. Der erste Monat ist kostenlos. Rein optional, wer lieber tippt, lässt es weg.
